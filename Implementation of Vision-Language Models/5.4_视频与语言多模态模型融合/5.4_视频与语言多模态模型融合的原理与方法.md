视频与语言多模态模型（Video-Language Models, Video-LLMs / 视频多模态大模型）的核心任务，是让模型同时理解**连续时空变化的视觉内容**与**离散符号化的自然语言**，并在两者之间建立精准的语义映射与推理能力。

相比静态图文（Image-Language），视频模态多出了**时间维度（Temporal Dimension）**和**高冗余 Token 爆炸**两大难题：一段数分钟的视频若逐帧切分 Patch，Token 数量很容易达到数万甚至数十万，直接送入大语言模型（LLM）会导致显存和计算开销急剧攀升。

### 一、 视频与语言融合的核心原理

视频与语言融合本质上围绕**表示对齐、时空建模与信息压缩**三个核心原理展开：

1. **异构空间与语义对齐（Representation & Semantic Alignment）**
* **维度与空间差异**：视觉编码器（如 ViT / SigLIP / 3D CNN / 3D VAE）输出的是连续的时空特征向量，而语言模型处理的是词嵌入空间（Embedding Space）中的 Token 序列。融合的第一步是通过投影或重采样模块实现维度匹配与语义空间映射。
* **细粒度与时序对齐**：不仅要知道画面里有“什么物体”，还要对齐“动作何时发生、因果顺序如何、语音/字幕与画面如何对应”。


2. **时空动态建模（Spatio-Temporal Modeling）**
* 视频不是孤立图片的简单堆叠，动作识别、状态变化和事件定位依赖跨帧关联。
* 需要在编码器内部（如时空注意力 / 3D 卷积 / 3D RoPE）或 Token 序列中显式注入时间与空间位置信息，防止模型把多帧当作无序集合。


3. **Token 压缩与上下文预算控制（Token Compression）**
* 原始视频帧序列冗余度极高（相邻帧背景变化小）。主流做法是通过时间池化、空间聚合、可学习 Query（如 Q-Former / Perceiver Resampler）或动态帧采样压缩视觉 Token 数量，在保留关键动作细节的同时适配 LLM 的上下文窗口。

### 二、 主流融合架构与方法分类

按融合发生的位置与交互深度，常见方法可分为以下几类：

#### 1. 早期融合 / 原生多模态融合（Early / Native Fusion）

* **做法**：将视频时空特征（甚至离散化后的视觉 Token）与文本 Token 在输入早期或统一 Backbone 的同一组自注意力层中直接拼接交互。
* **特点**：底层与跨模态交互最充分，适合需要强联合推理或统一生成/理解的原生多模态架构；但从头训练成本高，对长视频序列的长度管理要求极严。

#### 2. 中间融合（Intermediate Fusion，当前主流）

视觉特征提取后、进入语言解码或高层推理前，通过连接器（Connector）或注意力机制进行对齐与融合。常见实现方式包括：

* **投影拼接（MLP / Linear Projector + Token Concatenation）**：视觉特征经线性层或两层 MLP 映射到 LLM 嵌入维度后，与文本 Token 拼接输入 LLM（如 LLaVA 范式向视频扩展）。结构简洁、易于复用预训练视觉编码器与 LLM，但长视频需配合帧采样或时序压缩控制 Token 总量。
* **Query 压缩与重采样（Q-Former / Perceiver Resampler）**：用一组固定数量的查询向量（Learnable Queries）通过交叉注意力从海量视频特征中提炼关键信息，输出固定长度的视觉 Token。压缩率高、计算可控，但过度压缩可能丢失细微动作或小目标细节。
* **门控交叉注意力（Gated Cross-Attention）**：在语言模型层间插入交叉注意力模块，让文本状态主动“查询”视觉特征，并用门控机制调节视觉注入强度（典型代表如 Flamingo 路线）。

#### 3. 晚期融合（Late Fusion）

* **做法**：视频分支和文本/语音分支各自独立完成特征编码甚至初步预测，最后在决策层或高层表征层做拼接、加权或浅层融合。
* **特点**：模块化程度高、推理延迟可控、单模态缺失时具备一定鲁棒性；但缺乏细粒度的帧-词级早期交互，在复杂时序问答与细粒度推理上表现通常弱于中间/早期融合。

#### 4. 视频生成中的文本条件融合（DiT / 扩散架构场景）

* 在文生视频或视频编辑等生成式架构中，文本通常先经文本编码器或经过视觉对齐的多模态编码器提取语义表征，再通过 **Cross-Attention** 或 **单流 Token 拼接（Single-Stream Concatenation）** 注入到时空扩散 Transformer（如 DiT）的潜空间去噪过程中，以控制画面主体、运动与场景演进。

| 融合方式 | 交互时机 | 优势 | 局限性 | 典型适用场景 |
| --- | --- | --- | --- | --- |
| **早期 / 原生融合** | 输入层或统一主干早期 | 跨模态耦合深，联合表征能力强 | 训练算力开销大，长序列压力高 | 原生多模态大模型、统一理解与生成 |
| **中间融合（投影/重采样/交叉注意力）** | 编码后、推理/解码前 | 复用成熟视觉与语言基座，平衡效果与成本 | 视觉 Token 压缩与细节保留需权衡 | 视频问答（Video QA）、视频摘要、时序定位 |
| **晚期融合** | 高层或预测/决策阶段 | 架构解耦、模块独立、容错性好 | 细粒度跨模态交互有限 | 视频分类、多路信号辅助判断 |

### 三、 典型训练策略与优化要点

在实际构建或微调视频-语言模型时，融合效果高度依赖训练阶段的分工与目标设计：

1. **分阶段对齐与微调（Stage-wise Training）**
* **跨模态对齐阶段**：常冻结视觉编码器与 LLM，仅训练连接器（Projector / Resampler），让视觉特征进入语言模型的语义空间。
* **多模态指令微调阶段**：解冻部分或全部参数，使用视频描述、时序问答、图文交错及纯文本数据进行联合训练，兼顾视频理解与通用语言推理能力。
* **后训练与强化对齐**：针对复杂推理或特定领域任务，进一步引入偏好优化或可验证奖励强化学习，减少“看图编造”（视频幻觉）与时间错位。


2. **关键工程细节**
* **帧采样与时间编码**：均匀抽帧、关键帧/场景切分抽帧与可变帧率配合显式时间编码或时间戳对齐，直接影响长视频事件定位精度。
* **纯文本数据配比**：在指令微调中保留一定比例的纯文本数据，有助于防止 LLM 在接入视频特征后发生语言能力退化。
