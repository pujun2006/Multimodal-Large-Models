图像到文本生成（Image-to-Text Generation，涵盖图像描述 Image Captioning、视觉问答 VQA、文档理解 OCR 以及通用多模态大模型 VLM）的核心目标，是将高维、连续、空间结构化的**视觉信息**映射到离散、序列化的**自然语言词元（Token）空间**，并由语言模型自回归地生成连贯且贴合图像内容的文本。

现代主流方案普遍采用**模块化拼接（Modular VLM）**范式，即由**视觉编码器（Image Encoder）**、跨模态连接器/投影层（Multimodal Projector / Connector）**和**大语言模型/文本解码器（Text Decoder / LLM）三部分协同工作。

### 一、 核心架构组件

#### 1. 视觉编码器（Image Encoder）

负责将输入图像转换为紧凑且富含语义的视觉特征表示。

* **主流骨干网络**：
* **Vision Transformer（ViT）及其对比学习变体（如 CLIP-ViT、SigLIP）**：将图像切分为固定大小的 Patch（如 $14\times 14$ 或 $16\times 16$），加上位置编码后通过多层自注意力提取全局与局部特征。采用对比图文预训练（如 SigLIP）的编码器通常具有更强的语义对齐能力。
* **卷积神经网络（CNN，如 ConvNeXt）**：在局部纹理与高分辨率细节提取上表现稳定，常用于特定领域或轻量化场景。
* **原生多模态/统一视觉骨干**：部分新一代架构直接在统一 Transformer 中处理图像 Patch 序列，减少独立视觉塔带来的特征损耗。


* **高分辨率处理策略**：固定低分辨率（如 $224\times 224$ 或 $336\times 336$）会丢失小字、图表细节与远景物体。常见改进包括：
* **动态分块（AnyRes / Tile-based）**：将高分图拆分为多个子块分别编码，再拼接全局缩略图特征。
* **原生动态分辨率 ViT**：支持可变长 Patch 序列与 2D 旋转位置编码（2D-RoPE），避免强行裁切或拉伸破坏空间比例。



#### 2. 跨模态连接器（Multimodal Projector / Connector）

解决视觉特征维度与语言模型隐空间维度不匹配的问题，同时控制送入 LLM 的视觉 Token 数量以平衡计算开销。

* **MLP 投影层（Linear / MLP）**：最简洁高效的方案（如 LLaVA 系列），通常为两层线性层加 GELU 激活函数。保留了细粒度的空间网格信息，但高分辨率下 Token 数量较多。
* **重采样器 / 查询压缩模块（Perceiver Resampler / Q-Former）**：引入一组可学习的 Query 向量，通过交叉注意力（Cross-Attention）或自注意力从密集视觉特征中提炼固定数量的视觉 Token。优点是显著降低长序列推理显存，缺点是可能过滤掉局部细微信息。
* **空间下采样 / Pixel Shuffle**：在特征网格上做局部拼接或池化（如 $2\times 2$ 合并为 1 个 Token），在压缩长度的同时尽量保留二维空间排布。

#### 3. 文本解码器 / 大语言模型（Text Decoder / LLM）

承接对齐后的视觉 Token 与文本 Prompt Token，进行自回归预测。

* **自回归生成机制**：将视觉特征视为特殊的前缀或嵌入序列，与文本指令的 Token 嵌入拼接后输入 Decoder-only Transformer，按条件概率逐词生成输出：

$$P(Y \mid X_{\text{img}}, X_{\text{txt}}) = \prod_{t=1}^{T} P(y_t \mid y_{<t}, X_{\text{img}}, X_{\text{txt}})$$


* **交错图文序列（Interleaved Sequence）**：现代模型不仅支持“单图 + 文本”，还支持“多图 + 多轮文本”交错排列，通过特殊分隔符或位置编码让模型区分不同图像来源与时序/空间关系。

### 二、 典型训练范式与阶段划分

如上方架构图所示，现代图像到文本模型通常分阶段推进，以兼顾**跨模态对齐**与**指令跟随/推理能力**：

#### 阶段一：特征对齐 / 预训练（Alignment & Pre-training）

* **目标**：让视觉特征空间与语言模型的语义空间建立映射，使 LLM “听懂”视觉 Token 的含义。
* **常见策略**：冻结 Image Encoder 和 Text Decoder，仅训练 Multimodal Projector（或联合解冻部分视觉层），使用大规模图文对（Image-Caption pairs）进行下一个词预测（Next-Token Prediction）损失训练。
* **数据特点**：规模大、噪声容忍度高，涵盖日常物体、场景描述与基础 OCR 文本。

#### 阶段二：高分辨率与多任务持续预训练

* **目标**：增强细粒度感知、密集文本识别、图表解析与多图理解能力。
* **常见策略**：逐步提升输入图像分辨率，引入合成高质量描述数据、文档/表格/代码/数学图表数据以及交错图文语料，视情况解冻视觉编码器与部分语言层。

#### 阶段三：监督微调与对齐优化（SFT & RLHF / DPO）

* **监督微调（SFT）**：使用多样化的指令数据（详细描述、视觉问答、逻辑推理、格式化输出如 JSON/Markdown），训练模型按用户意图作答，减少死板复述。
* **偏好对齐（如 DPO、RLHF、GRPO）**：针对幻觉（Hallucination，即描述图像中不存在的物体、属性或关系）与推理步骤不严谨的问题，通过正负样本偏好对比或强化学习奖励机制，提升输出忠实度与复杂推理表现。

### 三、 关键工程挑战与设计权衡

| 设计维度 | 核心痛点 | 常见应对思路 |
| --- | --- | --- |
| **视觉 Token 数量与上下文长度** | 高清图像切分后会产生数百至数千个 Token，推高 Prefill 延迟与 KV Cache 占用 | 结合 Pixel Shuffle / Resampler 压缩 Token，或采用动态分辨率与高效注意力机制 |
| **空间位置与细粒度感知** | 扁平化为一维序列后，方位关系、计数、小目标易丢失 | 引入 2D 位置编码、高分切片机制，或在数据中强化空间定位与检测类任务 |
| **视觉幻觉** | 语言先验过强导致模型“脑补”未出现的细节 | 构建反事实/难负样本对齐数据、引入精细化描述训练、控制解码温度与长度 |
| **领域适配（OCR / 医疗 / 工业）** | 通用预训练模型在专业字体、密集表格或特定影像上准确率不足 | 针对性补充领域图文对、保留高分辨率细节、采用结构化输出微调 |

### 四、 评估指标与维度

* **传统生成指标**：CIDEr、BLEU、METEOR、ROUGE（侧重与参考描述的 n-gram 或语义重合度，在开放式 VQA 中局限性较大）。
* **现代多模态基准与 LLM-as-a-Judge**：评估综合感知、常识推理、数学与图表理解、文档抽取以及幻觉率，通常结合客观准确率与大模型裁判进行语义与逻辑评分。
