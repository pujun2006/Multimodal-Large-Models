**视觉问答（VQA）模型的任务建模**，本质上是定义一个从**视觉输入**与**自然语言问题**映射到**答案输出**的条件概率分布或决策函数。随着模型架构从传统判别式网络演进到多模态大模型（MLLM），任务建模也从“固定词表分类”逐步转向“自回归序列生成”与“多步推理建模”。

---

## 一、 形式化数学定义

设输入由视觉载体 $V$（单张图像 $I$、多图或视频帧序列 $\{I_1, I_2, \dots, I_T\}$）和自然语言问题 $Q = (q_1, q_2, \dots, q_m)$ 组成，目标输出为答案 $A$（以及可选的中间推理步骤或合理性解释 $R$）。

### 1. 判别式 / 分类式建模

早期 VQA 常将答案空间离散化为包含高频答案的候选词表 $\mathcal{A}$（例如 Top-K 答案集合），模型预测每个候选答案的概率分布：

$$P(a \mid V, Q; \theta) = \text{softmax}\big(f_\theta(V, Q)\big)_a, \quad a \in \mathcal{A}$$

* **优点**：推理速度快、输出格式规范、易于优化交叉熵或软标签损失。
* **局限**：无法回答词表外的开放词汇、长句或细粒度数值/文本答案。

### 2. 多选式建模

在多选 VQA 或视觉常识推理（VCR）中，给定候选答案集合 $\mathcal{C} = \{a^{(1)}, a^{(2)}, \dots, a^{(M)}\}$，模型分别计算每个候选项与 $(V, Q)$ 的匹配得分或条件对数似然：

$$\hat{a} = \arg\max_{a^{(j)} \in \mathcal{C}} s_\theta\big(V, Q, a^{(j)}\big)$$

### 3. 生成式 / 自回归建模（现代主流）

现代多模态大模型将答案 $A = (a_1, a_2, \dots, a_n)$ 视为 Token 序列，通过链式法则建模条件生成概率：

## 二、 核心建模模块拆解

无论采用哪种输出形式，完整的 VQA 任务建模通常围绕四个核心模块展开：

### 1. 视觉表征建模

视觉输入需要转化为可供跨模态交互的特征向量或视觉 Token 序列 $\mathbf{H}_V = \{\mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_N\}$：

* **全局 / 网格特征**：CNN 或 ViT 将图像划分为 patch 或特征网格，保留空间结构与整体语义。
* **区域 / 目标特征**：借助目标检测器提取显著物体区域特征，适合强调物体关系与局部属性的推理。
* **高分辨率 / 时序特征**：针对文档、图表或视频，通过分块切片、多尺度特征或帧采样压缩冗余视觉 Token。

### 2. 语言问题建模

问题文本 $Q$ 经分词与词嵌入后，通过文本编码器或语言模型底座提取上下文表征 $\mathbf{H}_Q$，捕捉疑问词类型（“是什么/有多少/为什么”）、修饰关系与约束条件。

### 3. 跨模态对齐与融合建模

这是决定模型能否“看懂问题所指之处”的关键，常见建模方式包括：

* **注意力交互**：利用交叉注意力（Cross-Attention）或共注意力（Co-Attention），让问题 Token 动态聚焦到相关视觉区域或 patch，反之亦然。
* **连接器映射**：在 MLLM 中，通过 MLP 投影、重采样器或查询向量将 $\mathbf{H}_V$ 对齐到语言模型的隐空间，与 $\mathbf{H}_Q$ 拼接后统一输入 Transformer 层进行深层融合。
* **视觉定位 / 接地（Grounding）**：在涉及指代、空间推理或常识解释时，显式建模文本引用与图像区域坐标/编号之间的对应关系。

### 4. 推理与解码建模

针对需要多步推导的问题（如数学图表、科学问答、因果推理）：

* **显式思维链（CoT）**：先生成观察描述或推理步骤 $z_1, \dots, z_k$，再生成最终答案 $A$，即建模联合分布 $P(z_{1:k}, A \mid V, Q)$。
* **知识增强建模**：引入外部检索上下文 $K$，将条件分布扩展为 $P(A \mid V, Q, K)$，降低纯参数记忆带来的幻觉。

## 三、 训练目标与损失函数设计

不同任务建模方式对应不同的优化目标：

| 建模范式 | 常见损失函数 | 关键细节与实践要点 |
| --- | --- | --- |
| **词表分类** | 二元交叉熵（BCE）/ 多标签软损失 | 标注往往存在多人投票分歧，常使用软目标分数而非单一硬标签 |
| **对比 / 多选匹配** | 交叉熵 / 对比损失（InfoNCE） | 正样本为正确选项，负样本为同题干扰项或批次内其他候选项 |
| **自回归生成** | Token 级交叉熵损失（NLL） | 通常仅对答案（及推理过程）部分计算损失，屏蔽提示词/问题部分的梯度 |
| **偏好与推理强化** | DPO / GRPO 等强化学习目标 | 常用于提升多步推理一致性、减少视觉幻觉及校准输出格式 |

## 四、 典型建模偏置与改进思路

在实际建模中，仅靠朴素的 $(V, Q) \rightarrow A$ 映射容易陷入两类陷阱：

1. **忽略视觉证据**：模型仅凭问题词频猜答案。改进思路包括构造反事实/互补样本对、引入区域级监督，或在推理时约束模型必须依赖视觉信息。
2. **跳步推理导致错误**：面对复杂推理题，直接输出答案容易出错。改进思路是把任务拆分为“感知定位 $\rightarrow$ 逻辑推导 $\rightarrow$ 答案归纳”的分步建模，并结合过程监督或可验证奖励进行后训练。
