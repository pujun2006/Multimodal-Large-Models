Few-shot Adaptation in Transfer Learning.py代码为一个**支持小批量迭代与概率评估的小样本（Few-Shot）LoRA 微调流程**。

下面按执行模块拆解其原理、代码作用与工程细节。

---


## 一、 随机种子与设备初始化

```python
def set_seed(seed: int = 42) -> None:
  random.seed(seed)
  np.random.seed(seed)
  torch.manual_seed(seed)
  if torch.cuda.is_available():
    torch.cuda.manual_seed_all(seed)

```

* **为什么小样本实验尤其需要固定种子**：样本量只有每类 4 条（共 8 条）时，数据打乱顺序（`shuffle=True`）、LoRA 矩阵 $A$ 的随机初始化、分类头初始权重以及 `dropout` 掩码，都会对最终准确率产生明显波动。固定种子便于对比不同超参数（如 `r`、学习率、epoch 数）的真实差异。
* **设备自动调度**：通过 `torch.cuda.is_available()` 自动选择 GPU 或 CPU；后续张量与模型均显式调用 `.to(device)`，避免设备不一致报错。

## 二、 模型加载与 LoRA 注入机制

```python
base_model = AutoModelForSequenceClassification.from_pretrained(
    model_name, num_labels=2
)

lora_config = LoraConfig(
    task_type=TaskType.SEQ_CLS,
    r=8,
    lora_alpha=16,
    lora_dropout=0.1,
    target_modules=["query", "value"],
    bias="none",
)
model = get_peft_model(base_model, lora_config).to(device)
model.print_trainable_parameters()

```

* **`task_type=TaskType.SEQ_CLS`**：声明任务类型为序列分类，帮助 `peft` 正确包装模型并保留分类头（`classifier`）参与训练。
* **`r=8` 与 `lora_alpha=16**`：
* `r` 是低秩分解的秩（rank），决定旁路矩阵 $B \in \mathbb{R}^{d \times r}$ 和 $A \in \mathbb{R}^{r \times k}$ 的容量。小样本场景下取较小秩（如 `4` 或 `8`），相当于给参数更新空间加了隐式正则化，降低过拟合风险。
* LoRA 更新量在缩放时通常按 <img width="94" height="44" alt="bce151dd-58a1-44c5-8b03-64f82d5e55e9" src="https://github.com/user-attachments/assets/555542d9-2f7a-4b17-b11a-4e8b840dc5a1" />
 调节步长比例（此处为 $16 / 8 = 2$），控制低秩旁路对主干输出的影响强度。


* **`target_modules=["query", "value"]`**：仅在 BERT 自注意力层的 `query` 和 `value` 投影线性层旁挂载 LoRA 分支，冻结原始 `bert` 参数（`requires_grad=False`）。`print_trainable_parameters()` 会直观打印可训练参数量、总参数量及占比（通常仅占约 $0.3\%\text{–}1\%$ 级别）。
* **`bias="none"`**：不额外训练偏置项，保持参数更新精简。

## 三、 小样本数据集与 `DataLoader` 批处理

```python
encoded = tokenizer(
    train_texts,
    padding=True,
    truncation=True,
    max_length=128,
    return_tensors="pt",
)
dataset = TensorDataset(
    encoded["input_ids"],
    encoded["attention_mask"],
    torch.tensor(train_labels, dtype=torch.long),
)
dataloader = DataLoader(dataset, batch_size=4, shuffle=True)

```

* `TensorDataset` + `DataLoader`：把 8 条样本封装为可迭代批次，每次取出 `batch_size=4` 的数据（每个 epoch 共 2 个 step，6 个 epoch 共 12 个 step）。相比原代码每 epoch 只有 1 个整批 step，小批量迭代能提供更频繁的梯度更新与随机扰动。
* 标签类型 `torch.long`：PyTorch 的 `nn.CrossEntropyLoss()` 要求分类标签为整型（`int64` / `long`），显式指定 `dtype=torch.long` 可避免类型不匹配问题。

## 四、 优化器过滤与训练循环

```python
trainable_params = [p for p in model.parameters() if p.requires_grad]
optimizer = torch.optim.AdamW(trainable_params, lr=1e-4, weight_decay=0.01)
criterion = nn.CrossEntropyLoss()

```

* **只传入可训练参数**：`[p for p in model.parameters() if p.requires_grad]` 确保优化器只为 LoRA 参数与分类头维护动量与二阶矩状态，既节省显存，又避免对已冻结参数做无效遍历。
* **学习率与权重衰减**：在低秩增量适配中，学习率常设在 `1e-4` 量级（高于全量微调常见的 `2e-5~5e-5`，因为只更新少量旁路与分类头）；`weight_decay=0.01` 用于抑制权重过度增长。
* **训练指标累计**：
* `model.train()` 开启训练模式（启用 dropout 等训练期行为）。
* `total_loss += loss.item() * labels.size(0)` 按样本数加权累计损失，最后除以 `total` 得到精确的平均每条样本损失，避免因最后一个 batch 样本数不同而导致平均统计偏差。

## 五、 推理评估与置信度输出

```python
model.eval()
with torch.no_grad():
  logits = model(**test_inputs).logits
  probs = torch.softmax(logits, dim=-1)
  predictions = torch.argmax(logits, dim=-1)

```

* `model.eval()` 与 `torch.no_grad()`：关闭 dropout 并禁用自动求导图构建，降低推理显存占用并加快前向速度。
* `softmax` 与 `argmax`：`logits` 是未归一化的类别得分；通过 `torch.softmax(logits, dim=-1)` 转成各类别概率分布，再用 `torch.argmax(logits, dim=-1)` 取概率最高的类别作为预测结果，同时打印对应置信度，方便排查模型是否出现“过度自信预测单一类别”的小样本常见现象。

## 七、 实际运行时的注意事项

* **仅 8 条样本的统计局限**：这段代码用于演示小样本 LoRA 的完整工程闭环与机制。在真实评估中，8 条样本方差很大，建议准备独立的验证集/测试集，或采用多次不同随机种子的平均准确率来衡量泛化性能。
* **任务适配扩展**：若目标任务不是二分类情感分析，只需修改 `num_labels`、`train_texts` / `train_labels` 与 `label_map` 即可复用同一套训练与推理骨架。
