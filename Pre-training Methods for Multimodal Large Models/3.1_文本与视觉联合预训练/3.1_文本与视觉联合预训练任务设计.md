文本与视觉联合预训练（Vision-Language Pre-training, VLP）的核心目标，是在大规模图文对（Image-Text Pairs）及交错图文数据上构建共享语义空间或跨模态推理能力，使模型能够同时处理检索、理解、定位与生成等任务。

在架构范式上，联合预训练任务通常围绕**双塔对比/对齐**、**单塔/多模态融合理解**、**自回归/生成**以及**细粒度区域-词元对齐**四大类展开。

## 一、 跨模态对齐与对比学习任务

这类任务通过拉近配对图文在嵌入空间中的距离、推远非配对样本的距离，建立全局语义对齐，广泛用于零样本分类与跨模态检索。

### 1. 图文对比学习（Image-Text Contrastive, ITC / InfoNCE）

* **机制**：在一个包含 $N$ 个图文对的 batch 中，图像编码器与文本编码器分别提取全局特征并做 $L_2$ 归一化，计算 $N \times N$ 的余弦相似度矩阵（乘以温度系数 $\tau$ 或可学习缩放参数），以对称交叉熵优化图像到文本与文本到图像两个方向。
* **关键细节**：
* **大 Batch 与负样本质量**：负样本数量直接影响表征质量，常结合分布式多卡 Gather、动量队列（如 MoCo 风格）或困难负样本挖掘（Hard Negative Mining）。
* **噪声监督**：网页爬取的 Alt-text 存在大量弱相关或噪声，需配合数据清洗、重Caption（Recaptioning）或软标签蒸馏缓解误推远。



### 2. Sigmoid 成对损失（Sigmoid Loss for Language-Image Pre-training, SigLIP）

* **机制**：将多分类 Softmax 对比转化为二分类 Sigmoid 损失，对矩阵中每一个 $(i, j)$ 图文对独立判定是否匹配（正样本标签为 $+1$，负样本为 $-1$）：

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{j=1}^{N} \log \frac{1}{1 + e^{z_{ij} \left(-t \cdot \langle \mathbf{v}_i, \mathbf{t}_j \rangle + b\right)}}$$



其中 $z_{ij} \in \{+1, -1\}$，t 为温度缩放参数，b 为偏置项。
* **优势**：无需在全局 $N \times N$ 矩阵上做归一化，降低了多机通信与显存开销，在中小 Batch 下也具有较好的训练稳定性。

## 二、 多模态融合与理解任务

当模型需要建模图像局部区域与文本词元之间的细粒度交互（如 VQA、图文蕴含、复杂指代）时，通常引入交叉注意力（Cross-Attention）或统一 Transformer 融合特征。

### 1. 图文匹配（Image-Text Matching, ITM）

* **机制**：输入图像与文本对，通过融合编码器输出表示后接二分类头，预测两者是否语义匹配（`1` 或 `0`）。
* **训练技巧**：常采用**难负样本采样（Hard Negative Mining）**——根据对比学习相似度分布，优先挑选相似度高但实际不匹配的文本或图像作为负样本，迫使融合模块捕捉细微属性、数量、空间关系与否定词差异。

### 2. 掩码语言建模（Masked Language Modeling, MLM）

* **机制**：随机遮蔽输入文本中的部分 Token（如 15%），让多模态编码器结合**未遮蔽的文本上下文**以及**整幅图像视觉信息**来预测被遮蔽的词元。
* **作用**：促使文本表征主动依赖视觉线索补全信息（例如句子中缺少颜色或物体类别时，必须从图像中读取）。

### 3. 掩码图像建模 / 掩码视觉建模（MIM / MVM）

* **机制**：遮蔽图像中一定比例的 Patch 或局部区域，预测被遮蔽块对应的语义特征、离散码本索引（如 VQ-VAE / Tokenizer 产出的 Token）或归一化像素/特征目标。
* **多模态视角**：在联合预训练中，视觉重建常与文本条件结合，或在现代多模态大模型（MLLM）中更多转向离散视觉 Token 预测与端到端视觉编码器特征对齐。

## 三、 生成与自回归任务

随着多模态大模型与统一生成架构的发展，自回归生成成为连接视觉理解与语言/图像输出的核心范式。

### 1. 图像条件语言建模（Image-to-Text Autoregressive / Captioning, Cap / LM）

* **机制**：以视觉特征为条件（通过 Prefix、Cross-Attention 或 Adapter/MLP 投影注入 LLM Token 空间），自回归预测文本序列：

* **价值**：相比简短的对比标签，生成任务能学习更丰富的语法结构、描述细节与指令跟随能力，也是构建多模态对话与 VQA 的基础。

### 2. 交错图文预测（Interleaved Image-Text Modeling）

* **机制**：直接在长文档或网页交错序列（如 `[Text] [Image_1] [Text] [Image_2] ...`）上进行自回归下一个 Token 预测（Next-Token Prediction）。
* **作用**：贴近真实世界多页文档、教程与图文混排上下文，有助于提升上下文学习（In-Context Learning）与多图推理能力。

### 3. 统一多模态生成（Any-to-Any / Discrete & Continuous Visual Generation）

* **机制**：将图像编码为离散 Token 后并入统一词表做自回归预测，或将文本/多模态隐状态作为条件输入扩散模型（Diffusion）/ 流匹配（Flow Matching）生成图像。
* **挑战**：视觉 Token 序列通常远长于文本 Token，且存在空间冗余与高频细节敏感问题，需要平衡生成保真度与计算成本。

## 四、 细粒度定位与结构化对齐任务

全局图文对齐容易忽略图像中的局部对象与属性。细粒度任务通过显式监督空间与结构信息来增强视觉 grounding 能力。

* **区域-词元对齐 / 指代定位（Grounded Pre-training / Phrase Grounding）**：将文本中的名词短语、属性或动作与图像中的 Bounding Box、Mask 或 Patch 特征对齐，提升目标检测、开放词汇识别（Open-Vocabulary Detection）与视觉问答的定位精度。
* **密集特征蒸馏（Dense Feature Distillation）**：将强视觉骨干（如自监督 ViT 或专业分割/检测模型）的特征图蒸馏到学生多模态视觉编码器中，弥补纯图文弱监督在细粒度空间与几何细节上的不足。

## 五、 核心任务对比与组合策略

| 任务类型 | 核心监督信号 | 典型能力收益 | 主要局限 |
| --- | --- | --- | --- |
| **对比对齐（ITC / SigLIP）** | 图文配对 / 成对匹配标签 | 零样本分类、跨模态检索、全局语义空间 | 细粒度空间关系与复杂逻辑推理较弱 |
| **图文匹配（ITM）** | 正负图文对（含难负样本） | 精细判别、属性/关系校验 | 推理开销高于纯双塔点积检索 |
| **掩码建模（MLM / MIM）** | 被遮蔽文本 Token / 视觉目标 | 跨模态上下文补全与局部表征学习 | 与下游生成/对话范式存在目标错位 |
| **自回归生成（LM / 交错）** | 下一个 Token 预测 / 条件生成 | 丰富描述、VQA、指令跟随与多轮交互 | 长视觉序列计算成本高，易出现幻觉 |
| **细粒度定位 / 蒸馏** | 区域框/掩码、教师特征图 | 空间定位、开放词汇感知、细节保留 | 细粒度标注成本高，依赖高质量数据/教师模型 |

### 实践中的组合设计要点

1. **分阶段调度（Stage-wise Curriculum）**：通常先用海量弱监督图文对做对比/对齐预训练打通语义空间，再引入高质量 Caption、交错图文、定位数据与指令微调数据进行融合与生成强化，最后在更高分辨率下微调以保留细粒度视觉信息。
2. **数据质量优先于单纯堆量**：高信息密度的合成描述（如详细场景拆解、OCR 文本提取）与去重过滤往往能显著减少模型幻觉并提升细粒度理解。
3. **目标冲突与权重平衡**：同时优化对比、匹配、掩码与生成损失时，需监控各子任务梯度幅度与收敛速度，避免单一任务主导或梯度互相拉扯。
