在多模态场景中，**对比学习（Multimodal Contrastive Learning）**的核心思想是将来自不同模态（如图像、文本、音频、视频）的**语义配对样本（正样本对）**在共享或对齐的向量空间中拉近，同时将**非配对样本（负样本对）**推远。与单模态对比学习依赖“同一样本的数据增强视图”不同，多模态对比学习天然利用**跨模态共现关系**（如图像与对应描述、视频与旁白/音频）构建监督信号。

---

## 一、 核心数学 formulation 与经典目标函数

假设一个批次（Batch）中有 $N$ 个跨模态样本对 $\{(x_i^{(m_1)}, x_i^{(m_2)})\}_{i=1}^{N}$（例如图像 $I_i$ 与文本 $T_i$）：

1. **编码与归一化**
* 分别通过模态编码器 $f_1(\cdot)$、$f_2(\cdot)$ 及投影头（Projection Head）得到特征向量 $u_i$ 与 $v_i$，通常做 $L_2$ 归一化得到单位超球面上的向量 $\hat{u}_i$、$\hat{v}_i$。
* 相似度通常采用余弦相似度缩放形式：$s(i, j) = \hat{u}_i^\top \hat{v}_j / \tau$，其中 $\tau$ 为温度系数（Temperature，可设为超参数或可学习参数）。


2. **双向 InfoNCE / CLIP 交叉熵损失**
* 从模态 1 检索模态 2 的损失 $\mathcal{L}_{1 \to 2}$ 与反向损失 $\mathcal{L}_{2 \to 1}$ 对称计算：

$$\mathcal{L}_{1 \to 2} = -\frac{1}{N}\sum_{i=1}^{N} \log \frac{\exp(\hat{u}_i^\top \hat{v}_i / \tau)}{\sum_{j=1}^{N} \exp(\hat{u}_i^\top \hat{v}_j / \tau)}$$


* 总损失常取双向均值：$\mathcal{L}_{\text{CLIP}} = \frac{1}{2}(\mathcal{L}_{1 \to 2} + \mathcal{L}_{2 \to 1})$。


3. **Sigmoid 对比损失（SigLIP 路线）**
* 传统 InfoNCE 需要在批次内计算全量 `softmax` 分母，在大 Batch 或多卡 AllGather 时通信与归一化开销较大。
* **SigLIP** 将多分类交叉熵改写为独立的二元交叉熵（Pairwise Sigmoid Loss），把每个 $(i, j)$ 对视为正样本（$y_{ij}=1$）或负样本（$y_{ij}=-1$），显著降低了对超大 Batch 的依赖并提升了训练稳定性与效率。

## 二、 典型架构与实现路线

| 架构路线 | 交互方式 | 优势 | 局限性 |
| --- | --- | --- | --- |
| **双塔 / 全局对比（如 CLIP、SigLIP、ALIGN）** | 图像与文本各自独立编码，仅在最终全局向量层计算点积/余弦相似度 | 特征可离线预计算与缓存，检索极快、扩展性好，零样本分类能力强 | 缺乏细粒度局部交互（如“谁在谁左边”、复杂属性绑定、密集计数较弱） |
| **细粒度 / Token 级对齐（如 FILIP、局部-全局对比）** | 在 patch embedding 与 word/token embedding 之间计算最大相似度聚合 | 保留局部区域与词语的细粒度对应，提升精细检索与定位能力 | 需存储或计算更多 token 级交互，显存与计算成本更高 |
| **融合编码器 + 对比/匹配联合训练（如 ALBEF、BLIP）** | 先用双塔对比对齐单模态特征，再通过交叉注意力融合做图文匹配（ITM）与生成（LM） | 兼顾全局检索效率与深度跨模态推理、描述生成能力 | 训练流程与多任务损失权重设计更复杂 |
| **多模态统一 / 多锚点对比（如 ImageBind、LanguageBind）** | 以图像或文本为枢纽（Bind），将音频、深度、热成像、视频等多模态对齐到同一空间 | 无需所有模态两两成对，即可实现任意模态间的涌现式跨模态检索与对齐 | 枢纽模态若存在偏差或噪声，会向其他模态传导 |

## 三、 工程实现关键细节

### 1. 负样本构造与分布式训练

* **批内负样本（In-batch Negatives）**：默认将同一 Batch 内其余 $N-1$ 个样本作为负样本。Batch Size 越大，负样本覆盖越充分，表征区分度通常越高。
* **多卡 AllGather 与梯度处理**：在 DDP（分布式数据并行）下，通常通过 `all_gather` 汇聚各卡的特征向量以扩大负样本池；需注意仅对**本卡本地样本**保留计算图梯度，对其他卡收集的特征做 `stop_gradient`（或按框架规范处理），避免梯度回传错位。
* **队列 / 动量编码器（如 MoCo 思路在早期多模态工作中的应用）**：当 Batch 受限于显存时，可通过特征队列或动量更新编码器扩充负样本数量，但需留意特征陈旧导致的分布漂移。

### 2. 温度系数 $\tau$ 与训练稳定性

* 温度系数 $\tau$ 控制相似度分布的尖锐程度：$\tau$ 过小会使梯度集中在少数“困难负样本”上导致训练震荡或坍塌；$\tau$ 过大则会削弱区分能力。
* 常见做法是将 $\log(1/\tau)$ 设为可学习标量参数，并设置上下限裁剪（Clamp），防止训练早期或后期出现数值爆炸。

### 3. 数据噪声与硬负样本（Hard Negatives）

* 网络爬取的图文对往往包含弱相关或噪声文本（如网页模板词、无关标签）。若直接将弱正样本视作严格负样本，会破坏语义空间结构。
* 可引入**软标签 / 动量伪目标**（用动量模型预测的相似度分布作为软监督目标，缓解噪声标签误伤）或**困难负样本挖掘**（挑选语义相近但描述不同的样本对，提升模型对细微差异的辨别力）。

### 4. 下游应用模式

* **零样本分类（Zero-Shot Classification）**：将类别名填入 Prompt 模板（如 `"a photo of a {label}"`）经文本编码器得到类别原型向量，与图像特征计算相似度即可完成分类，无需微调分类头。
* **跨模态检索与多模态 RAG**：将图像/视频/音频与文本映射到同一向量空间后，结合向量索引（如 FAISS）实现以文搜图、以图搜文或跨模态知识召回。
* **作为 VLM 的视觉底座**：预训练好的视觉编码器常作为多模态大语言模型（VLM）的视觉特征提取器，再接投影层或连接器输入 LLM 进行复杂推理与生成。
