Data Fusion.py代码构建了一个**特征级多模态分类模型**（`BERT` 提取文本特征 + `ResNet50` 提取图像特征 + 双向交叉注意力/自注意力融合 + 线性分类头），并包含完整的单步训练演示。整体分为四个部分：

---

### 1. 单模态特征提取器（`FeatureExtractor`）

* **文本分支（`encode_text`）**：使用 `BertTokenizer` 分词并输入 `BertModel`，得到 `[B, L, 768]` 的隐藏状态。随后利用 `attention_mask` 对有效 token 求加权平均，避免 `[PAD]` 填充位稀释句向量。
* **图像分支（`encode_image`）**：将 `PIL.Image` 统一转为 `RGB`，缩放到 `224x224` 并按 ImageNet 均值与标准差归一化；通过 `resnet.fc = nn.Identity()` 移除原 1000 类分类头，输出 `[B, 2048]` 的全局池化特征。
* **骨干冻结控制（`freeze_backbones`）**：当 `freeze_backbones=True` 时，将 `text_encoder` 和 `image_encoder` 参数的 `requires_grad` 设为 `False`，减少显存占用并加快前期验证。

---

### 2. 特征级融合模块（`ModalFusion`）

* **维度投影**：`text_projection`（`768 -> fusion_dim`）与 `image_projection`（`2048 -> fusion_dim`）各自接 `GELU`，把异构特征映射到同一维度 `fusion_dim`，再增加序列长度维得到 `[B, 1, fusion_dim]`。
* **双向交叉注意力（`use_cross_attention=True`）**：
* `t2i_attn`：文本特征作为 `query`，图像特征作为 `key/value`，经残差连接与 `norm1` 归一化。
* `i2t_attn`：图像特征作为 `query`，文本特征作为 `key/value`，经残差连接与 `norm2` 归一化。
* 取两路输出的均值 `0.5 * (t_out.squeeze(1) + i_out.squeeze(1))` 得到联合表示 `[B, fusion_dim]`。


* **自注意力分支（`use_cross_attention=False`）**：将两个模态向量沿序列维拼接为 `[B, 2, fusion_dim]`，送入 `self_attn` 做自注意力交互，经残差与 `norm1` 后对序列维取均值。
* **输出层（`output_layer`）**：两层线性变换配合 `GELU` 与 `Dropout`，输出最终融合特征 `[B, fusion_dim]`。

---

### 3. 端到端分类封装（`MultimodalClassifier`）

* **串联流程**：依次调用 `extractor.encode_text` 与 `extractor.encode_image` 获取单模态向量，再送入 `fusion` 生成联合表征，最后由 `classifier`（`Linear(fusion_dim, num_classes)`）输出分类 `logits`（`[B, num_classes]`）。
* **梯度与计算图细节**：当前 `forward` 中对 `text_feats` 和 `image_feats` 调用了 `.detach()`，意味着**即使传入 `backbone_grad=True`，梯度也不会回传到 `FeatureExtractor` 的编码器输出之前**，仅更新 `ModalFusion` 与 `classifier` 的参数。若后续需要微调骨干网络，需去掉 `.detach()` 并确保对应参数的 `requires_grad=True`。

---

### 4. 辅助工具与训练演示（`__main__`）

* **`_load_or_create_dummy_images`**：若当前目录缺少 `cat.jpg` 或 `dog.jpg`，自动生成两张 `300x300` 纯色占位图以便直接运行验证维度与梯度流；正式训练应替换为真实样本及 `DataLoader` 批处理。
* **训练闭环**：构造二分类标签 `labels` 与 `AdamW` 优化器（仅过滤 `requires_grad=True` 的参数），执行前向计算、交叉熵损失 `F.cross_entropy`、反向传播 `loss.backward()` 与参数更新 `optimizer.step()`。
