Multi-task shared learning.py代码实现了一个**支持图像缺失处理的多模态多任务学习框架**，同时联合训练两个任务：**图文匹配（ITM，二分类）**与**多模态情感分析（MM-Sentiment，三分类）**。整体采用“双编码器 + 投影对齐 + 跨模态注意力融合 + 共享表示 + 多任务头”的经典结构，并在训练阶段加入了余弦对齐辅助损失与不确定性损失加权。

---

### 一、 核心模块逐段解析

#### 1. `MultimodalMultiTaskDataset`：多模态数据集与缺图容错

* **输入与编码**：使用 HuggingFace `AutoTokenizer` 对 `text` 做定长 padding/truncation，输出 `input_ids` 和 `attention_mask`。
* **图像缺失处理**：检查 `has_image` 与 `image` 是否有效；若缺图（如第 2 个任务里的 `"Standard delivery status update."`），`pixel_values` 会退化为全零张量 `[3, 224, 224]` 且 `has_image` 设为 `False`。
* **潜在注意的点**：如果 `item["image"]` 是 PIL Image 或未归一化的张量，实际业务中建议在 Dataset 或 transform 中统一做 resize 与归一化，使其分布与 `ViTModel` 预训练输入一致。

#### 2. `MultimodalMultiTaskModel`：双编码器、跨模态融合与多任务头

* **双模态编码与投影层**：
* `text_encoder`（默认 `bert-base-uncased`）输出序列特征 `[B, L, D_t]`，经 `text_proj` 映射到统一维度 `proj_dim`（默认 512），并取 `[CLS]` 位置作为 `text_pooled`。
* `vision_encoder`（默认 `google/vit-base-patch16-224`）输出 patch 序列特征 `[B, N, D_v]`，经 `vision_proj` 映射到同一 `proj_dim`。


* **可学习缺图占位向量（`missing_img_token`）**：
* 当样本缺图时，用 `torch.where` 将 `vis_seq` 替换为 `missing_img_token` 的扩展张量。相比直接用全零视觉特征进入后续层，可学习的占位向量能让模型专门学到“当前无图像”的语义表示，减少零特征带来的噪声干扰。


* **跨模态注意力与共享表征**：
* `cross_attn` 以 `text_seq` 为 `query`，以 `vis_seq` 为 `key` 和 `value`，让每个文本 token 去检索相关的图像 patch 信息。
* 对注意力输出做均值池化得到 `vis_pooled`，与 `text_pooled` 拼接后经过 `fusion_norm` 和 `shared_mlp`，生成供多任务共用的特征向量 `shared_repr` `[B, P]`。


* **多任务输出头与 `log_vars**`：
* `itm_head` 输出 2 维 logits（匹配/不匹配）；`sentiment_head` 输出 3 维 logits（如负向/中性/正向）。
* `log_vars` 为每个任务维护一个可学习的对数方差参数 $\log \sigma_t^2$，用于动态平衡不同任务的损失量级。



#### 3. `compute_multitask_loss`：任务损失、对齐损失与不确定性加权

* **任务损失**：根据当前 batch 的 `task` 调用对应头计算 `CrossEntropyLoss`。
* **跨模态余弦对齐损失（`align_loss`）**：
* 仅对 `has_image == True` 的样本计算 `1 - cos(text_emb, vis_emb)` 的均值，拉近有效图文对在共享空间中的方向一致性；若有效图像样本数小于 2，对齐损失置 `0.0`。


* **不确定性加权（Kendall et al. 风格）**：
* 加权公式为：

$$\mathcal{L}_{\text{weighted}} = \exp(-s_t)\mathcal{L}_{\text{task}, t} + 0.5 s_t$$



其中 $s_t = \text{log\_vars}[t]$。损失噪声/尺度较大的任务，模型倾向于增大 $s_t$ 以降低梯度主导权重，同时 `0.5 * s_t` 防止 $s_t$ 无限制趋向正无穷。
* 总损失为 `weighted_task_loss + align_weight * align_loss`。



#### 4. `train_multimodal_multitask`：分层学习率与混合步调度

* **分层学习率**：预训练的 `text_encoder` 和 `vision_encoder` 使用较小学习率（`2e-5`），避免破坏原有预训练表征；投影层、跨模态注意力、MLP 和任务头使用较大学习率（`1e-4`），加快新结构收敛。
* **打乱任务调度（`schedule`）**：将两个 DataLoader 的 step 拼接后随机打乱（`random.shuffle(schedule)`），让模型在同一个 epoch 内交替更新两个任务，而不是先全训完任务 A 再训任务 B。
* **梯度裁剪**：`clip_grad_norm_(model.parameters(), max_norm=1.0)` 用于缓解多任务联合训练及跨模态注意力初期的梯度波动。

### 三、 细节说明

1. **`batch["task"][0]` 的假设**：
当前写法假设一个 batch 内所有样本属于同一 `task`。如果未来改为**单 batch 内混合不同任务样本**，不能只取 `task = batch["task"][0]`，而应按样本所属任务掩码分别计算各自头部的损失再聚合。
2. **缺图样本的跨模态注意力细节**：
当前 `vis_seq` 在缺图时被替换为重复的 `missing_img_token`，`cross_attn` 仍会正常计算注意力权重；若希望更严格地表示“缺图”，也可结合 `has_image` 在融合或损失阶段做进一步区分。
