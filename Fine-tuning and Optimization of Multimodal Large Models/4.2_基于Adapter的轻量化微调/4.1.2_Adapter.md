Adapter.py代码实现了一个基于 **PyTorch** 和 **Hugging Face `transformers`** 的 **Adapter 微调分类器**（以 `bert-base-uncased` 为例）。它不直接修改 Transformer 源码，而是通过冻结基座权重 + 注册前向钩子（Forward Hook）的方式，在每层注意力与前馈输出处动态插入瓶颈式 Adapter 模块。

---

### 一、 整体架构与工作流程

1. **基座冻结**：加载预训练模型后，将 `self.base_model` 所有参数的 `requires_grad` 设为 `False`，阻止梯度回传更新基座权重。
2. **钩子挂载**：遍历 BERT 编码器的每一层（`encoder.layer`），在 `layer.attention` 和 `layer.output` 后注册前向钩子，将对应子层的输出送入独立的 `AdapterLayer`。
3. **局部训练**：优化器仅接收 `requires_grad=True` 的参数（即所有 `AdapterLayer` 和 `classifier`），反向传播时梯度仍会流经冻结层以更新上游 Adapter，但基座参数保持不变。
4. **轻量导出**：训练结束后通过 `get_trainable_state_dict()` 只提取可训练权重保存到 `adapter_weights.pt`，避免保存完整的预训练模型。

---

### 二、 核心模块逐段解析

#### 1. `AdapterLayer`：瓶颈式 Adapter 模块

```python
class AdapterLayer(nn.Module):
    def __init__(self, hidden_size: int, adapter_dim: int, init_std: float = 1e-3):
        super().__init__()
        self.down_proj = nn.Linear(hidden_size, adapter_dim)
        self.act = nn.GELU()
        self.up_proj = nn.Linear(adapter_dim, hidden_size)
        ...

```

* **结构**：`down_proj`（降维）→ `GELU`（非线性激活）→ `up_proj`（升维），最后在 `forward` 中执行 `x + ...` 残差相加。
* **初始化策略**：`weight` 使用较小标准差的正态分布（默认 `1e-3`），`bias` 初始化为 `0`。这使得训练初期 Adapter 的旁路输出接近于零，整体行为近似恒等映射（`x + 0 ≈ x`），有助于平稳起步。

#### 2. `_make_adapter_hook`：兼容 Tuple 输出的前向钩子

```python
def _make_adapter_hook(adapter: AdapterLayer):
    def hook(module, inputs, output):
        if isinstance(output, tuple):
            adapted_first = adapter(output[0])
            return (adapted_first,) + output[1:]
        return adapter(output)
    return hook

```

* 在 Hugging Face 模型中，某些子模块（例如注意力模块）前向传播可能返回 `(hidden_states, ...)` 元组，而另一些模块可能直接返回张量。
* 该钩子判断 `output` 是否为 `tuple`：若是，只对首个元素（隐状态张量）做 Adapter 变换并重新拼接其余元素（如注意力权重或 past key/values）；若不是，直接变换整个 `output`。

#### 3. `AdapterClassifier`：模型组装与权重提取

* **模块注册**：将 `attn_adapters` 和 `ffn_adapters` 放入 `nn.ModuleList`，确保它们作为子模块被正确注册到 `AdapterClassifier` 中（可被 `.to(device)`、`.train()`/`.eval()` 和 `.parameters()` 识别）。
* **插入位置**：
* `layer.attention`：在自注意力子模块输出处插入 `attn_adapter`。
* `layer.output`：在 BERT 层后半段前馈网络输出（含残差/LayerNorm）处插入 `ffn_adapter`。


* **前向与分类**：取 `outputs.last_hidden_state[:, 0, :]`（即 `[CLS]` 位置的表示）送入 `self.classifier` 输出类别 `logits`。
* **`get_trainable_state_dict()`**：筛选出 `requires_grad=True` 的参数名，并从 `state_dict()` 中提取对应张量转至 CPU 保存，实现轻量级权重导出。

#### 4. `main()`：训练与保存闭环

* 使用 `bert-base-uncased` 对两条示例文本进行分词编码（`padding=True, truncation=True`）。
* 优化器选用 `AdamW`，学习率设为 `1e-3`（Adapter/分类头微调通常可使用比全量微调更大的学习率，这里仅作为最小可运行示例）。
* 循环 3 个 epoch 执行前向计算、交叉熵损失、反向传播与参数更新，最后调用 `model.eval()` 并保存可训练权重。

### 四、 潜在细节与工程注意事项

* **BERT 架构兼容性**：代码直接访问 `self.base_model.encoder.layer` 以及 `layer.attention`、`layer.output`，这是 BERT 类编码器模型的结构；若替换为 RoBERTa 或其他架构，需确认对应属性路径。
* **钩子句柄管理**：`register_forward_hook(...)` 会返回一个 `RemovableHandle` 对象。当前代码未保存该句柄；如果后续需要在同一进程中动态卸载或替换钩子，建议保留句柄并在不需要时调用 `.remove()`。
* **推理加载配套**：当前代码实现了**保存**可训练权重（`adapter_weights.pt`），但尚未编写对应的**加载**逻辑。实际部署时，需先实例化相同的 `AdapterClassifier`，再用 `model.load_state_dict(torch.load("adapter_weights.pt"), strict=False)` 恢复 Adapter 和分类头参数。
* **示例数据规模**：`main()` 中仅用了 2 条样本和 3 个 epoch，仅用于验证前反向传播与保存流程是否通畅，实际任务需替换为完整数据集、划分验证集并调整超参数。
