Decision-level fusion.py代码实现了一个**支持模态可用性掩码（Missing-Modality Mask）与可学习概率加权的决策级融合（Late Fusion）二分类原型**。它的核心设计思路是：**文本分支与图像分支各自独立完成特征映射与单模态分类预测（输出概率分布），随后仅在决策层按可学习权重与样本可用性对概率做加权汇总**。

下面从**整体工作流**、**核心类逐一拆解**、**训练与推理流程**以及**工程细节与可拓展方向**四个部分详细说明：

---

### 一、 整体工作流概览

1. **单模态独立预测**：`text_input`（`[B, 128]`）与 `image_input`（`[B, 256]`）分别送入各自的 `UnimodalBranch`，各自得到独立的预测 `logits`（`[B, C]`），再经 `softmax` 转换为单模态类别概率分布 `text_probs` 与 `image_probs`。
2. **动态权重与缺失归一化**：将可学习的 `branch_weight_logits` 经 `softmax` 转为非负基础权重，再乘以样本级可用性掩码（`text_avail`、`image_avail`），最后除以有效权重之和进行归一化，确保某一路模态缺失时权重自动归零并由其余有效模态承担。
3. **决策层概率融合与对数概率输出**：按归一化权重对两路概率做加权求和得到 `fused_probs`，取对数并做下限裁剪（`clamp(min=1e-8)`）得到 `fused_log_probs`，配合 `nn.NLLLoss()` 计算损失。
4. **训练与多场景推理验证**：训练 5 个 Epoch 观察 Loss 与基础权重变化；推理时通过 `test_image_avail` 模拟第 3 条样本图像缺失，观察其有效权重如何自动回退到文本分支。

---

### 二、 核心模块逐一解析

#### 1. `UnimodalBranch`（单模态独立预测分支）

* **结构组成**：`Linear(input_dim, hidden_dim)` → `ReLU(inplace=True)` → `Dropout(dropout_rate)` → `Linear(hidden_dim, num_classes)`。
* **职责边界**：与特征级融合不同，该模块直接输出类别维度的 `logits`（`[B, num_classes]`），相当于一个完整的单模态预测头，不向另一模态暴露中间隐层特征。

#### 2. `DecisionLevelFusionModel.__init__`

* **双分支实例化**：`self.text_branch` 与 `self.image_branch` 分别处理文本与图像输入，各自独立训练与推理。
* **可学习分支权重参数**：
```python
self.branch_weight_logits = nn.Parameter(torch.zeros(2))

```


初始化为全 `0`，经 `softmax` 后初始基础权重为 `(0.5, 0.5)`，可在训练中随任务损失自动调整两路模态的相对重要性。

#### 3. `DecisionLevelFusionModel.forward`

* **单模态概率计算**：
* `text_logits = self.text_branch(text_input)`、`image_logits = self.image_branch(image_input)`
* `text_probs = torch.softmax(text_logits, dim=-1)`、`image_probs = torch.softmax(image_logits, dim=-1)`
* 之所以在概率空间而非直接对 `logits` 加权，是为了让各分支输出处于同一 `[0, 1]` 概率尺度，便于与可用性掩码结合做凸组合。


* **可用性掩码与权重归一化**：
* `text_avail` 与 `image_avail` 默认为全 `1`（形状 `[B, 1]`），`0` 表示该样本对应模态缺失或不可用。
* `eff_w_text = w_text * text_avail`、`eff_w_image = w_image * image_avail`。
* `weight_sum = (eff_w_text + eff_w_image).clamp(min=1e-8)`：加上 `1e-8` 下限避免极端情况下出现除零 `NaN`；随后分别除以 `weight_sum` 得到 `norm_w_text` 与 `norm_w_image`。


* **概率加权融合与辅助输出字典**：
* `fused_probs = norm_w_text * text_probs + norm_w_image * image_probs`
* `fused_log_probs = torch.log(fused_probs.clamp(min=1e-8))`：防止概率接近 `0` 时 `torch.log(0)` 产生 `-inf` 导致梯度异常，输出可直接接入 `nn.NLLLoss()`。
* 返回 `fused_log_probs` 与 `aux_outputs` 字典，方便在训练和调试时查看各分支原始 `logits`/概率及每条样本的实际融合权重。

### 三、 `main()` 训练与推理流程解析

1. **模拟输入与图像缺失掩码**：
* 生成 `batch_size=16` 的随机 `text_data`、`image_data` 与二分类 `labels`。
* `image_avail = (torch.rand(batch_size, 1, device=device) > 0.25).float()` 让约 `25%` 的样本在训练时图像分支不可用，促使模型在部分样本缺图时依赖文本分支做预测。


2. **训练循环（5 个 Epoch）**：
* 每次迭代执行 `optimizer.zero_grad()` → 前向计算 → `criterion(fused_log_probs, labels)`（`NLLLoss`） → `loss.backward()` → `optimizer.step()`。
* 打印每个 Epoch 的 `Loss` 以及当前 `Base Weights (Text, Image)`，直观观察权重演化。


3. **推理阶段与权重回退验证**：
* 构造 4 条测试样本，设置 `test_image_avail = tensor([[1.0], [1.0], [0.0], [1.0]])`，即第 3 条样本（索引 `2`）图像缺失。
* 在 `model.eval()` 与 `with torch.no_grad():` 下完成前向推理，打印 `Test Predictions` 以及每个样本对应的 `Effective Text Weights` 和 `Effective Image Weights`。在第 3 条样本上可以看到图像有效权重变为 `0.0`、文本有效权重变为 `1.0`。

### 五、 实际工程中的关键注意点

1. **极端双模态全缺失边界（`text_avail == 0` 且 `image_avail == 0`）**：当前代码在两路同时为 `0` 时，`weight_sum` 会被 `.clamp(min=1e-8)` 截断，此时 `norm_w_text` 与 `norm_w_image` 都会变成 `0`。若真实场景可能出现双模态全缺失，建议增加一个缺省先验/兜底类别分布逻辑，避免出现零权重组合。
2. **概率校准与分支过拟合**：当某个单模态分支容量过大或训练充分、另一分支较弱时，联合训练下权重可能向强分支倾斜；实际工程中常先分别验证各单模态分支性能，再做决策层融合或元学习器（Stacking MLP）调优。
3. **模拟数据仅验证链路**：当前输入与标签为随机生成，用于验证前向结构、掩码权重归一化、损失反传与推理流程是否正常，接入真实任务需替换为真实特征与标注数据。
