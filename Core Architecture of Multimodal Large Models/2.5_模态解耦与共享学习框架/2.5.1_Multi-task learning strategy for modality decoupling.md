Multi-task learning strategy for modality decoupling.py代码在双模态多任务框架的基础上，使用**共享/特有双分支特征拆分**与**正交解耦损失**，让图像与文本特征在进入任务预测前先做子空间分离，再按任务需要组合特征。

---

### 一、 整体数据流转与设计逻辑

整个前向与训练流程可以概括为四步：

1. **单模态基础编码**：`img_input`（`[B, 256]`）和 `text_input`（`[B, 128]`）分别经由 `ModalityEncoder` 提取维度为 `hidden_dim`（`64`）的基础特征 `img_base` 与 `text_base`。
2. **共享与特有双分支拆分**：`DisentangledBranch` 将每个模态的基础特征分别映射到两个独立的投影子空间（维度均为 `branch_dim=32`），得到跨模态共享特征（`img_shared`、`text_shared`）和单模态特有特征（`img_specific`、`text_specific`）。
3. **共享融合与任务专属拼接**：
* `SharedFusionLayer` 将 `img_shared` 与 `text_shared` 沿特征维拼接并融合，得到联合共享特征 `joint_shared`（`[B, 64]`）。
* 图像任务头接收 `cat((joint_shared, img_specific), dim=1)`（维度 `64 + 32 = 96`），文本任务头接收 `cat((joint_shared, text_specific), dim=1)`（维度 `64 + 32 = 96`），从而在利用跨模态共性的同时保留各自模态的独有信息，减少另一模态无关特征的直接干扰。


4. **多任务损失与正交解耦联合优化**：总损失由图像分类损失、文本分类损失以及正交解耦损失加权组成，通过一次 `backward()` 同步更新所有参数。

---

### 二、 核心模块与函数逐一解析

#### 1. `ModalityEncoder`（单模态基础编码器）

* 由 `Linear -> ReLU -> Dropout` 组成，负责将不同输入维度的原始特征映射到统一的基础隐层维度 `hidden_dim`（`64`）。
* 相比原版把 `ImageEncoder` 和 `TextEncoder` 写成两个几乎相同的类，这里合并为可复用的 `ModalityEncoder`，参数与结构更清晰。

#### 2. `DisentangledBranch`（共享/特有双分支模块）

* 内部包含 `shared_proj` 与 `specific_proj` 两个独立的全连接 + `ReLU` 子网络，各自输出 `[B, branch_dim]` 的特征向量。
* 这种结构把“抽取共性”和“保留模态独有信息”交给两个不同的线性+非线性映射去学习，为后续解耦损失提供可约束的表征接口。

#### 3. `SharedFusionLayer` 与 `TaskHead`

* **`SharedFusionLayer`**：接收 `img_shared` 和 `text_shared`（拼接后为 `branch_dim * 2 = 64` 维），经过 `Linear -> ReLU -> Dropout` 输出 `out_dim`（`64` 维）的联合共享特征。
* **`TaskHead`**：轻量线性分类层 `nn.Linear(in_dim, output_dim)`，分别用于输出图像 10 分类 `logits` 和文本 2 分类 `logits`。

#### 4. `compute_orthogonal_loss`（正交解耦损失函数）

```python
s_norm = F.normalize(shared, p=2, dim=-1, eps=eps)      # [B, D]
p_norm = F.normalize(specific, p=2, dim=-1, eps=eps)  # [B, D]

cross_gram = torch.matmul(s_norm.transpose(0, 1), p_norm) / shared.size(0)
return torch.sum(cross_gram ** 2)

```

* **L2 归一化**：沿特征维度（`dim=-1`）对 `shared` 和 `specific` 做 L2 归一化，消除向量模长差异对内积大小的直接影响，`eps` 防止零向量除零。
* **跨子空间 Gram 矩阵与平方和**：`s_norm.transpose(0, 1)` 形状为 `[D, B]`，与 `p_norm`（`[B, D]`）相乘并除以 `batch_size`，得到 `[D, D]` 的跨子空间相关性矩阵；对其元素取平方并求和（等价于 Frobenius 范数的平方），当共享维度与特有维度趋于正交、相关性接近 `0` 时，该损失值趋近于 `0`。

#### 5. `DisentangledMultiTaskModel.forward`

* 返回三项内容：`img_output`（`[B, 10]`）、`text_output`（`[B, 2]`）以及包含四个中间特征张量的字典 `aux_feats`，方便在训练循环中直接取出 `img_shared`、`img_specific`、`text_shared`、`text_specific` 计算解耦损失或做特征分析。

---

### 三、 训练循环与推理评估说明

* **总损失构成**：
```python
ortho_img = compute_orthogonal_loss(aux["img_shared"], aux["img_specific"])
ortho_text = compute_orthogonal_loss(aux["text_shared"], aux["text_specific"])
ortho_loss = ortho_img + ortho_text

total_loss = w_img * img_loss + w_text * text_loss + w_ortho * ortho_loss

```


其中 `w_img = 1.0`、`w_text = 1.0` 控制两个分类任务的相对权重，`w_ortho = 0.1` 控制正交约束的正则强度。
* **训练与推理细节**：
* 训练阶段（`model.train()`）启用 `Dropout`，每步执行 `optimizer.zero_grad()` -> 前向计算 -> `total_loss.backward()` -> `optimizer.step()`，并打印各子损失与总损失。
* 评估阶段（`model.eval()` + `torch.no_grad()`）关闭 `Dropout` 与梯度追踪，通过 `torch.argmax(..., dim=1)` 得到图像与文本的预测类别索引。
* 示例中的输入和标签仍为随机张量，主要用于验证双分支拼接维度、正交损失计算与梯度反传链路是否顺畅；实际应用中需替换为真实多模态特征与标注数据。
